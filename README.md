# Face Exchange

Face Exchange is a standalone Astro prototype about how interfaces turn facial images into measurable, comparable and exchangeable value.

The project does not use real face recognition, AI APIs, uploads, databases, login, or persistent image storage. Camera and uploaded images stay local inside the browser session.

## Commands

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Editing

- Edit stage text in `src/pages/index.astro`.
- Edit packaging modes and default values in `src/scripts/faceExchange.js`.
- Edit the visual system in `src/styles/global.css`.
